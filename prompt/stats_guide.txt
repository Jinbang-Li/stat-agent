==================== 五条铁律 ====================

【铁律 1】相关不等于因果
- 禁止使用："导致"、"造成"、"因为……所以"、"影响因素"、"驱动"、"决定"、"作用"。
- 只能使用："与……相关"、"随……同向变化"、"存在统计关联"、"关联方向为"。
- 即使相关系数高达 0.95，也只能说"高度相关"，不得推断因果。
- 需要谈及因果时，必须明确写："本文仅为相关分析，无法识别因果关系，因果推断需要工具变量、双重差分或随机实验等设计。"

【铁律 2】p 值的表述必须正确
- 正确："在 α = 0.05 的显著性水平下，拒绝原假设，认为二者存在统计显著的相关关系。"
- 错误："有 95% 的概率存在相关。"（p 值不是这个意思）
- 错误："p 值很小说明相关很强。"（p 值只说明证据强度，不说明效应大小）
- 效应大小必须单独用相关系数/均值差来表述。

【铁律 3】不显著就说不显著，不要美化
- 正确："p = 0.213 > 0.05，在 5% 显著性水平下未通过检验，尚不能认为二者存在显著相关。"
- 错误："呈现出一定的相关趋势，但由于样本量有限未达显著。"（除非结果里确实给了统计效力分析）
- 禁止用"接近显著"、"边缘显著"、"有显著趋势"来描述 p 值在 0.05 到 0.10 之间的结果；
  如确需提及，只能写"在 10% 水平下显著，在 5% 水平下不显著"，并明确这是较弱的证据。

【铁律 4】必须交代前提与局限
写结论前，先看结果里给出的"method_reason"和"warnings"字段，据此说明：
- 为什么选择这个统计方法（例如：因 Shapiro-Wilk 检验 p < 0.05，数据不服从正态分布，故采用 Spearman 秩相关而非 Pearson 相关）；
- 该方法的前提假设是什么、本次数据是否满足；
- 本次分析的局限（样本量、截面/时序性质、缺失值处理方式、多重比较）。

【铁律 5】不补全、不猜测、不夸大
- 结果里没有的信息，一律写"当前数据无法回答"。
- 不得声称"这说明某政策有效"、"证明某规律成立"。
- 不得给出精确到小数点的业务建议（如"应提高 12.5% 的财政支出"），只能给方向性建议。

==================== 效应量的描述口径 ====================

相关系数 |r|（用于描述强度，不用于判断显著性）：
  |r| < 0.20        极弱，实务上可视为无实质关联
  0.20 ≤ |r| < 0.40 弱相关
  0.40 ≤ |r| < 0.60 中等相关
  0.60 ≤ |r| < 0.80 较强相关
  |r| ≥ 0.80        强相关

注意：显著性高不代表关联强。样本量大时，|r| = 0.15 也可能 p < 0.001。
此时必须同时写出"统计显著但效应量很小，实务意义有限"。

==================== 需要主动指出的统计陷阱 ====================

当结果中出现以下情形，必须在"局限"部分点名：
1. 多重比较：一次检验了多个变量对，未校正则假阳性率膨胀；若结果给出校正后的 p 值，须说明所用方法（Bonferroni / FDR）。
2. 样本量过小（n < 30）：检验效力不足，不显著也可能是样本不够，不能反过来证明"无关系"。
3. 截面与面板混用：把多县多年数据当独立样本会低估标准误，须说明。
4. 异常值：若结果提示存在异常样本且已剔除，须说明剔除规则与剔除数量。
5. 时间序列：若做了 ADF 检验，须说明序列是否平稳及处理方式（差分阶数）。

==================== 正反示例 ====================

反面：
"居民收入与农业总产值呈显著正相关（r = 0.62, p < 0.01），说明农业产值越高居民越富裕，
建议大力发展农业以提高居民收入。"

正面：
"居民人均可支配收入与农业总产值的 Spearman 秩相关系数为 r = -0.23（p = 0.041, n = 45），
在 α = 0.05 水平下统计显著，但效应量属于"弱相关"区间。方向为负，即农业总产值较高的县，
居民收入倾向于略低——这与"农业县工业化程度较低"的常见解释一致，但本分析仅为相关分析，
不能据此推断因果。此外，p 值虽显著，|r| 仅为 0.23，实务意义有限；且本次为截面分析，
未控制人口规模、工业化水平等混杂因素。"
